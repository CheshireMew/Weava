# 后台 API 参考

此文件由 `node --import tsx scripts/generate-api-docs.ts` 从 `packages/contracts/src/admin-api.ts` 生成。不要手工修改表格；更改接口定义后重新生成，测试会检查是否同步。

服务端请求与成功响应校验、后台和 CLI 的客户端、此表及 OpenAPI 共用同一份定义。`schema --format openapi` 返回完整的参数、请求体、成功响应与错误响应 JSON Schema；`schema --format types` 导出站点条目类型及客户端入口。

除登录状态与登录接口外，接口需要站主 Cookie 或 Bearer 凭据。`202` 表示后台任务已接收，使用 `GET job/{id}` 查询结果。错误响应为 `{error:string,details?:JSON}`；`409` 需要重新读取修订并重新预检。扩展字段、统计维度行与不同任务的结果在相应字段中保留开放 JSON，字段的业务规则由领域服务继续检查。
