## 已完成的优化

| 界面问题 | 修改结果 |
| --- | --- |
| 辅助文字过浅，字号层级不一致 | 后台共享颜色变量，统一说明与控件字号，明确选中、焦点、警告和错误状态；使用 Windows 系统字体 |
| 手机宽度隐藏筛选，列表挤成横向条带 | 700px 以下分别展示完整列表和编辑器，筛选保持可用；返回列表前保存工作稿并恢复焦点 |
| 手机导航覆盖内容而未隔离操作 | 原生模态导航抽屉，有关闭入口、Esc 关闭和焦点返回 |
| 发布、预览、版本弹窗缺少完整键盘行为 | 共用原生 Dialog，背景隔离、焦点管理、提交时防重复和禁止中途关闭；版本读取失败可重新读取 |
| 媒体上传入口无法正常通过键盘使用 | 使用按钮触发文件选择，搜索框获得初始焦点；区分加载、空媒体库和无搜索结果 |
| 操作缺少可见反馈 | 登录显示提交状态；媒体保存和复制显示反馈；网络、超时、无效响应给出明确提示；裁切取消或失去指针捕获后停止拖动 |
| 搜索和任务刷新重复发请求 | 文本搜索等待 180ms 稳定后查询，忽略过期查询结果；定时任务刷新在上一请求完成后再计时 |
| 前台阅读和窄屏细节不一致 | 明确搜索标签与无结果反馈、日期遵循站点语言、长标题换行、表格和代码约束在正文内；菜单支持 Esc 和外部点击关闭 |
| 正文图片只支持鼠标，SVG 放大可能缩为零宽 | 图片使用可聚焦按钮，Enter 打开原生预览，Esc 关闭并返回原图片；预览与触发容器明确尺寸；主题隐藏的封面不生成无效按钮 |
| Newsletter 长英文推荐标题超出手机页面 | 对头条、列表、卡片和推荐标题统一处理长单词换行，复核无整页横向溢出 |

按实际源码颜色计算，列表辅助文字与背景的对比度由约 2.66:1 提高到 5.57:1；占位文字由约 2.19:1 提高到 5.79:1。Newsletter 辅助文字在白底上为约 5.74:1。后台语义颜色和交互规范见仓库根目录 `DESIGN.md`。
