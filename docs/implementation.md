## 关键验证

核心测试覆盖不可变版本、保存冲突、发布事务失败、公开搜索隔离、不兼容字段修改、任务重试、正文处理、Sharp 派生图、统计去重、备份损坏、空目录恢复、迁移重复执行及目标编辑保护。可重复脚本位于 tests 和 scripts；测试夹具、截图及运行日志位于 D:\Tools\cache\weava。

最终核心测试共 15 项通过，TypeScript 检查和生产构建通过。媒体上传通过独立任务生成派生图片，并验证重复请求只创建一个任务、srcset 和媒体响应；全新空站点也能在首次发布前预览指定草稿修订。

生产 API 检查证明，新增内容网址和主题配置发布后，进程编号与程序构建时间均未变化。写入使用修订号，重复异步请求使用同一任务编号。历史恢复进入工作稿，不自动改变公开版本；撤下同时更新路由和搜索。

浏览器完成可视化文章及表格编辑、自动保存、真实页面预览、发布、修改后的公开隔离、历史入口、归档、新页面区块发布、桌面与窄屏操作。专项检查验证中文、表格、图片与代码在 Markdown 和可视化之间往返，断线输入恢复到编辑器，以及两个窗口之间的 409 冲突。

迁移公开网址 1,070 个，另有 1 条归档隐藏记录。原创 Markdown 36 篇，已有作者历史 36 份；来源资料、布局与附件保留在独立实例。来源基线核对 5,812 个文件，差异为零。全量引用检查中，缺失网址、内部媒体和目录锚点均为零。重复迁移没有创建新公开版本或重复历史；隔离测试确认目标被修改时报告冲突，不覆盖该修改。

迁移实例的最终完整备份包含 5,905 个文件，已逐项 SHA-256 校验并恢复到新的 D 盘目录。恢复后 1,071 条工作记录、1,070 个公开网址、4,541 个媒体文件和公开版本编号一致，数据库完整性检查为 ok。备份和恢复位置记录在下面的 backup.json 中；历史文件继续保留。

真实中断检查强制结束了运行中的服务与任务进程。重启后，已结束的任务被明确标记为失败，没有误报成功或重复提交；重新发起备份后正常完成，公开版本和程序构建保持不变。仍存活的任务进程继续被跟踪，进程已经结束的任务进入失败状态。恢复测试也覆盖服务仍在运行时拒绝恢复，以及目录切换中断后根据日志恢复原站点。

## 性能与来源可用性

使用同机 Chrome、相同内容与图片、10 Mbps／40 ms 网络条件，双方启用 gzip、禁用浏览器缓存。外部视频及实时接口同时排除，只比较页面呈现。单次实验不代表公网 Core Web Vitals。

迁移站的文章示例传输约 27 KB，旧站参考约 28 KB；主要脚本 gzip 后约 7.7 KB，文章统计脚本约 2.3 KB。普通前台没有请求 React 后台、Lexical 或管理组件。后台自身的主脚本约 107 KB gzip，编辑器另约 117 KB，在进入编辑功能时加载；这些开销与前台分开记录。

Astro 动态页面仍承担服务器处理时间。最终一轮代表页 TTFB 约 49–151 ms，静态参考约 7–21 ms；较早的一轮服务首次请求还包括模块、站点快照和扩展初始化，单次记录约 706 ms。没有把动态网站描述成比原静态站更快，也没有使用依赖目录大小代替网页传输量。精确逐页结果见 performance.json。

真实请求中，4 组公告与 8 个已确认的股票来源刷新成功，视频样本取得 file.notion.com 的 302 跳转。StockPlus 来源仍未确认，单独显示 unavailable。故障注入验证所有来源请求失败时，上一份公告和股票成功数据仍保留。实时目录数量和临时视频地址会变化，以 services.json 的检查时间为准。

## 报告与边界

本机报告目录为 D:\Tools\cache\weava\acceptance：

| 文件 | 内容 |
| --- | --- |
| api.json | 修订冲突、任务幂等、动态发布、真实备份、撤下与无需重启 |
| editor.json | 格式往返、断线恢复、多窗口冲突 |
| media.json | 后台媒体任务、重复请求、派生图、公开页面响应图片与媒体服务 |
| migration.json | 全量网址、内部引用、目录锚点与来源校验 |
| backup.json | 完整迁移实例备份及恢复一致性 |
| lifecycle.json | 重复实例拒绝、端口占用退出、原服务保持运行 |
| restart.json | 真实中断后的任务状态、重试与公开版本保留 |
| services.json | 真实公告、股票、视频和中文搜索检查 |
| performance.json | 相同条件下的逐页传输量和显示时间 |
| public-boundary.json | 私有值、实例数据、核心依赖边界与许可原文校验 |

浏览器截图和完整结果另保存在同级 browser-* 目录，最终干净实例的截图位于 acceptance/final。验收用示例实例整体归档在 acceptance/demo-instance；当前 E 盘 demo 是重新初始化的正式示例，没有验收文章和测试页面。归档与备份不自动清理。

旧站复杂页面保留明确的兼容 HTML 布局，原创正文为 Markdown，来源正文为可编辑 HTML；它们没有被无损改造成全部原生区块。兼容块可以继续保留，也可以逐块替换。自定义代码区块通过版本化扩展声明与 API 配置；后台内置区块提供专用表单。主题代码、组件和服务端扩展变化需要重新构建，日常内容和配置发布不需要。

当前发布快照保存完整版本，旧站复杂 HTML 的数据库和内存开销高于普通示例；历史与快照没有自动清理。空间检查可以查看内容数据库、版本、媒体、备份及未引用媒体。此实现选择保留可恢复的数据，并未将长期磁盘占用描述为零成本。

验收仅覆盖 Windows 本地与本地能取得的统计数据，没有验证 Linux、服务器最新统计、公网 TLS、线上域名切换或第三方来源未来可用性。会员、支付、电商、多租户和实时协同不属于本次功能。
