# 使用与编辑

文章顶栏将分类、标签、封面和发布选项与预览、发布放在同一行；窄屏时设置行自动换行。编辑界面的封面按原始比例显示，高度最多为 280 像素或视口高度的 32%，超高时整体缩小。代码块独占一块空间，右上角可复制完整代码，保留缩进和换行。

正文编辑默认保存为 Markdown。旧文在修改正文或切换 Markdown 时转换：文字、图片、图片链接、图注、列表、表格和代码保留，音视频及嵌入内容转换为普通链接；旧站的样式和非 Markdown 属性不再带入。代码里的 HTML、缩进和空行保持原样，列表中的代码使用带缩进的代码围栏。打开已有笔记时光标位于开头。

编辑器与前台共用 Markdown 语法解析，支持各级标题、强调、删除线、引用与嵌套列表、任务项、普通及引用式链接、图片、表格对齐和单元格换行。反引号围栏、波浪围栏及缩进式代码都保留缩进和空行；`linenos` 和 `{2,3}` 行号、标记行选项在编辑转换后保留。宽表格与长代码在自身区域滚动。普通页面、文章、笔记详情、笔记时间流和预览中的代码均可复制；内嵌预览由父页面处理复制，仍保持预览脚本禁用。

文章列表有多种内容类型时，点击“新建内容”明确选择文章、文档或其它已配置类型；按类型筛选后，新建按钮会直接显示对应名称。新建并返回列表保留原来的搜索、状态、类型和页码。收起筛选面板后，类型、可见性和其它生效条件仍显示在列表上方，可以逐项移除或清除筛选。

侧栏显示文章、媒体、评论和访问统计；配置笔记类型的网站还显示独立的“笔记”入口。网站设置提供基本信息、关于本站、友情链接、外观、导航与分类、搜索与分享、广告。后台不提供页面搭建、内容类型配置、后台布局或批量发布计划页面。需要定制数据结构、来源核验或批量发布时，由外部工具通过 CLI／API 操作；已有数据和计划继续保留。

博客模板的“随笔”入口统一为 `/notes/`，按发布时间倒序显示文章和笔记。正式文章使用文字配右侧小封面的紧凑卡片，标题最多两行、摘要一行，点击进入原文章。短笔记直接显示正文和小图，长笔记默认显示三行预览，可通过“展开笔记／收起笔记”查看完整内容，支持鼠标和键盘操作。后台的“笔记”入口使用独立的简洁列表，直接写正文，点击“发布”即生效；修改已发布笔记时点击“保存修改”，不经过文章发布确认。笔记没有封面、随机封面、草稿分类、类型筛选或文章管理工具，列表标题从正文提取。编辑中的内容会自动保留以防丢失，发送前不会公开；私密内容不进入公开时间线。导入的 HTML 笔记直接以正常正文编辑，保留链接和图片。笔记详情和随笔时间线不展示文章广告，旧笔记正文内追加的 WordPress 推广卡片也会清理。新内容的网址继续使用类型前缀加随机八位十六进制标识，并检查网址是否已被内容或旧网址占用；改标题不会自动改网址。

点击“写笔记”或列表中的笔记，会在当前列表上打开编辑弹窗，不跳转到独立写作页面。弹窗正文独立滚动，关闭和发布操作保持可见；长笔记可以滚动到最后一段。新建后直接关闭空白窗口不会生成空笔记。文章与笔记的列表按各自查询保存，切换时不会短暂显示另一类内容。

已有网站启用时，由 CLI／API 为内容类型设置 `format: "note"`（原 `wordpress-moment` 类型也会自动识别为笔记），为随笔页面使用 `notes-feed` 模板，并将 `settings.extensions.notes.path` 与导航设为该页面路径。启用后 Newsletter 首页和文章归档只列正式文章。普通程序升级不会自动启用或移动已有页面；改变归档入口时应保留 301 跳转，已有文章和笔记详情网址可继续使用。

分类与标签整合在“网站设置 → 导航与分类”，点击条目就地改名，网址与层级按需展开，导航在同一分区调整。网站设置、分类标签、媒体信息和评论设置在停止输入约一秒后自动保存；未完成的必填字段会暂缓保存，失败时保留输入并提供重试。网站设置自动保存成功后直接更新公开网站，无需再点击保存或应用。更新完成后在底部短暂提示“已保存并生效”，标题下不常驻保存状态；更新失败会保留已保存的设置，持续显示原因并提供重试。写作时选择或新建分类、标签直接在顶部弹层完成。新评论是否需要审核在“评论 → 评论设置”中调整，修改后自动保存并更新前台。文章编辑页默认使用可视化编辑，收起管理导航，顶部保留返回、保存状态、预览和发布。格式工具栏上方常驻分类、标签、封面、发布选项和更多设置；公开/私密与评论使用开关。作者、网址、摘要和搜索分享集中在“更多设置”中。检查、历史版本和本地草稿位于左下角“更多编辑操作”。

打开 `/admin/`，使用站主账户和密码登录，已有实例的默认账户名是 `owner`。开启两步验证后还需输入验证码或恢复码。后台“账户”可修改资料和密码、撤销其他登录、设置两步验证；恢复方法见[运行与恢复](operations.md)。内容列表可以按标题、状态、可见性和类型筛选，并按页加载。新建内容后填写标题和正文，通过顶部工具栏设置网址、作者、分类、标签和封面。分类标签可以从已有项目勾选或查找，也可以输入新名称添加；底层使用稳定编号，改名后关联保留。

新建内容默认使用可视化模式，提供标题、加粗、斜体、列表、引用、链接、代码、表格、媒体、撤销和重做。选中表格单元格后可以增删行列；插入媒体可从公用媒体库选择，插入后可以修改说明、图注或更换文件。链接可以从内容库选择，保存为稳定内容关联。旧站文章和笔记的普通 HTML 正文转换为同样的可编辑内容，保留文字、链接、图片、表格、代码和原段落锚点；旧主题注入的推广块不属于正文，文章推广卡片由独立设置展示一次。兼容的旧 HTML 直接显示正常正文，不要求用户阅读代码。Markdown 模式保留源码；指令或特殊语法继续使用源码模式。操作反馈在几秒后自动消失，离开对应编辑界面时清除；尚待处理的保存冲突、恢复草稿和正在运行的任务仍在相关操作处显示。

内容列表每行右侧的“⋯”菜单提供编辑、复制和删除。复制会打开一份正文及设置独立的新草稿，生成新网址，不自动发布。删除需要确认，会从内容库移除并撤下公开页面；内容库没有恢复入口，既有历史快照和共享媒体保留。待执行的发布任务、定时发布或仍引用该内容的发布计划需要先处理。顶部只显示全部、已发布、草稿；有未发布修改时在对应文章旁提示，归档内容在筛选中查看。

文章和笔记正文可以直接拖入本地图片，支持一次拖入多张，上传后按顺序插入放下的位置；已有 HTML 正文同样支持。源码模式插入到当前光标处。媒体库可在面板内直接拖入多个文件，并沿用当前分组。上传显示进度，失败的文件可以重试；保存、发布和离开编辑页会等待正在进行的上传完成。

输入停止约一秒后自动保存草稿，也可以按 Ctrl+S。浏览器会保留尚未保存的内容，重新打开时提供恢复入口。另一窗口已经保存时，后台暂停自动保存并打开对比：不同位置的改动可以合并，同一位置的改动需要选择本地或服务器内容。正文作为完整单元选择，避免把两种编辑格式混在一起。对比后服务器再次变化会要求重新比较。

浏览器按文章异步保存，每篇只保留一份最新的未保存草稿，持续覆盖更新；网站保存成功后清除对应草稿，不保留本地历史副本。最多保留四十篇、总量约 3 MiB。关闭或刷新网页前仍有未保存修改时，会触发浏览器的离开确认；确认框的文字由浏览器决定，网页不能自定义。存储失败会提示，网站保存仍可继续。上传媒体时按分块显示进度，中断后重新选择同一文件可继续已确认的部分。

“历史版本”可以选择两个修订，对照正文、字段和页面实际效果。恢复会创建新的工作稿，当前公开页面保持原版本。

草稿允许暂时缺少必填字段，已填写字段仍需符合其类型。发布会检查必填项和引用，未完成时给出具体错误。

“预览”先保存工作稿，再通过真实 Astro 渲染器打开指定修订，可切换桌面和窄屏宽度。预览不计入统计。只有点击发布后，新内容才进入前台；保存不会改变已经发布的页面。

点击文章“发布”先查看本次变更，再确认发布。查看后工作稿或公开版本变化会要求重新查看。网站设置保存后自动应用站点设置和分类标签，不发布文章工作稿；“备份与维护 → 发布记录”中的全站发布会更新已有公开内容的改稿。

文章顶部“发布选项 → 定时发布”可安排发布时间，保存当时选定的修订；随后编辑的新工作稿仍然保留。计划在服务运行时到期执行，停机期间到期则在启动后补执行。待执行计划可以取消；失败会显示原因，可以重试同一修订或取消后重新安排。

CLI／API 的批量发布计划按实际时刻判断到期，新保存的时间统一为 UTC，已有带时区的计划也按相同规则执行。若计划要撤下的公开修订已经变化或已被撤下，计划会记录失败原因，后续到期计划继续执行；需要重新检查并保存计划后再执行。发布校验期间的短暂数据变化会等待下一次检查，不会覆盖新工作稿。

搜索与分享默认沿用文章标题、摘要、封面、作者和网址。“更多设置 → 搜索与分享 → 单独修改搜索与分享内容”可覆盖标题、摘要和图片。页面语义、作者身份及规范地址不再出现在普通表单中，既有特殊配置继续生效，外部工具仍可修改。

来源核验和文档分组不再出现在日常文章设置中。已有记录随内容保留，确需维护时通过 CLI／API 修改。新建模板不再拦截写作入口，重复写作可以复制已有文章。

留言板使用独立的 `guestbook` 页面模板及原生评论系统，导航可直接链接到原有留言板网址；不把旧留言复制到正文里展示。文章、笔记和留言板的每条公开评论都可点赞或取消点赞，状态随访客保留。开放评论时提供回复按钮，填写区显示回复对象，也可取消回复；回复继续使用现有审核和验证码流程，保留父评论关系。关闭新评论后保留既有评论和点赞，收起回复入口。

网址别名和网站检查不再提供后台页面，侧栏也没有“更多管理”入口。文章更改网址时自动保留旧链接跳转；手动补充历史链接、检查页面和读取搜索数据由外部工具通过 CLI／API 完成。数据格式及 CLI 入口见[搜索与内容改进](seo-improvements.md)。

内容设置中的“可见性”支持公开和私密，与草稿、发布、归档状态独立。私密文章或页面发布后，只有登录后台的站主可以打开其网址，未登录访问返回 404；访客内容列表、搜索、RSS、站点地图和导航不包含它。修改可见性后点击发布才改变当前访客版本。私密页面和预览禁止缓存与索引，也不计入访问统计。

私密内容专用的本地媒体及响应式图片同样需要登录；如果同一张图片也被当前公开内容或公开设置引用，该图片属于共用的公开资源。历史私密修订引用的图片继续受到保护，撤下文章不会使这些图片公开。已有旧数据未设置可见性时按公开处理。

“网站设置 → 友情链接”直接填写名称、网址和简介；“关于本站”填写介绍文字。有内容时自动显示，清空则隐藏，无需启用开关。自动保存后更新固定前台界面及页脚入口。旧页面沿用原网址，未编辑的旧内容不擅自转换。

文章目录由正文标题自动生成，不需要配置布局。历史导入内容及由外部工具维护的文档结构继续按原配置渲染。

内容类型、自定义字段、字段组、模板及区块权限由 CLI／API 管理，普通后台不提供设计器。已有自定义字段值保留，读取和编辑已有文章不会重置这些配置。

文章分类关联使用稳定编号，分类改名后关联保留。首页自动显示已有公开文章的分类，不必再勾选一份目录。导航直接选择目标、填写名称并上下移动；已有子导航保留，但普通后台不再提供创建多层菜单的功能。

网站设置中的站名、介绍、颜色、页脚和导航会自动保存并更新前台。新增主题代码或扩展代码仍需要程序构建。账户、密码、导入、发布和图片裁切等操作仍需主动执行。

“网站设置 → 广告”提供四个固定位置。普通广告直接填写标题、文字、链接并选择图片；已有复杂广告在隔离预览中编辑文字和图片，未编辑前保留原始代码。每个广告位提供“启用”和“代码”两个开关：打开代码开关后，同一编辑区域切换为代码输入框，关闭后返回直接编辑。切换编辑方式不会保存或改写广告内容。启停保留广告内容，自动保存后直接在前台生效，文章预览使用当前保存的设置。

Newsletter 文章页提供点赞、评论、分享和自动生成的侧边目录。封面用于列表和分享预览，不额外插入正文，摘要也不重复显示在文章开头。

Newsletter 首页侧栏直接填写文字及链接名称、网址，样式由主题负责。旧侧栏在打开表单时只读取，首次编辑后使用固定样式展示；原始 HTML 保存在旧配置中，不因打开表单而丢失。

默认主题和 Newsletter 均提供评论。访客无需注册即可填写称呼和评论，或选择已有评论回复；Newsletter 还提供点赞和取消点赞。评论必须通过图片验证码，验证码五分钟有效、单次使用，填写错误后需要换一张；同时限制验证码请求和评论提交频率。后台“评论”按状态筛选、分页浏览，可以审核、隐藏、恢复或以站主身份回复。独立站主标识只由服务端授予，访客使用同名不会获得该标识。隐藏评论不进入前台列表和计数，回复不显示隐藏父评论的称呼。互动数据保存在站点 SQLite 数据库中，随目录备份保留；私密文章和编辑预览不开放访客互动。

媒体库直接上传文件，上传过程自动生成网页需要的响应式图片。图片详情保留名称、说明、图注，在图片上点击或拖动选择焦点。点击“裁切图片”后可以拖动框选，也可以按 Tab 进入选区，用方向键移动、Shift + 方向键调整大小；按住 Alt 可精细调整，Home 或“重置选区”恢复整张图片。裁切保留原图及来源关系，归档不移除文件，也不影响已发布页面。

在分组内重复上传同一文件时，会复用已有媒体并更新分组，保留名称、说明、图注和图片焦点；仍可在媒体详情中主动修改或清空说明和图注。

续传按文件内容校验，文件名和大小相同但内容不同的文件会重新上传。外部工具使用分块上传 API 时，创建上传必须提供完整文件的 SHA-256 值；浏览器和 `media-upload` 命令会自动计算。旧的 JSON/base64 上传入口继续可用。

JSON 导入预检、导入、删除、撤下、安排定时发布和保存发布计划返回后台任务，可在“备份与维护 → 任务记录”查看进度或取消。HTTP 应答或进度查询中断不代表任务停止；应先读取任务结果。CLI 的 `import`、`schedule create`、`publication-plan save` 支持 `--wait`；`job --id <任务编号> --cancel` 请求取消。任务默认执行期限为 30 分钟，可通过 `WEAVA_JOB_TIMEOUT_MS` 配置；取消或超时会停止执行线程，已原子提交的成功结果仍保留。

“备份与维护 → 维护”显示暂存文件和导入资料占用，可以取消未完成上传，并预览、确认清理已经结束或过期的暂存文件。正在执行的任务、接收中的分块、未登记文件和目录链接不会进入清理范围；预览后文件或任务状态发生变化，需要重新检查。上传和 JSON 请求的暂存文件不进入完整备份，恢复备份后未完成的上传、导入需重新选择文件。

广告停用时收起编辑表单，点击“编辑”可以修改保留的内容而不启用广告。启用后展开表单，停用仍保留文字、图片和代码。

“备份与维护”提供 JSON 交换和 WordPress 标准 WXR 导入。选择文件和选项后先预检，再导入；预检后来源、选项或站点内容变化需要重新预检。转换报告列出页面、类型、分类、附件、评论和未转换的来源功能。未知插件区块、动态区块和短代码会要求在编辑页检查后才能发布。详细范围见迁移文档。


后台的短设置直接显示，分类编辑、图片裁切、媒体网址、备份位置和历史详情通过独立弹窗操作。首页推荐顺序直接列出推荐文章；文章的搜索与分享设置在自己的页签中填写。访问统计通过“概览、来源、访客、设备、行为”页签切换，共用日期与筛选条件，趋势可切换为图表或数据表。每张支持导出的报表旁直接导出对应数据。备份显示当前保存位置，通过“更改位置”和“检查已有备份”分别操作；历史整理采用默认保留策略，执行前展示将整理的数量，并保留恢复入口。账户页保留资料、密码、两步验证和登录会话，后台地址和外部工具令牌通过 CLI 管理。

笔记发布只确认提交时的版本。等待发布期间继续写的内容会留在编辑器，并显示尚未发布。尚未首次保存到网站的笔记也能从列表的本地恢复入口找回。不同窗口的未保存内容分别保留，恢复时可选择副本；保存成功只确认相应会话和内容，不清除另一窗口的新稿。本地恢复数据设有容量上限，满额时明确提示，不会自动丢弃其它未保存文章。

评论回复在明确发布前始终是草稿。切换回复、离开后台页面或关闭窗口时受编辑保护，刷新后可恢复文字；离开操作不会代替点击“发布回复”。后台页面或代码分块出错时可局部重试，编辑会话保留在工作区；重新载入前先保留未保存内容，保留失败时停留在当前页并提示原因。
