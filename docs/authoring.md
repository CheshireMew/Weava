# 使用与编辑

侧栏显示内容、媒体、评论和访问统计。网站设置提供基本信息、关于本站、友情链接、外观、导航与分类、搜索与分享、广告和高级设置。后台不提供页面列表、页面画布或模板布局管理。备份与维护及更多管理中的其它入口保留；切换设置分区会保留尚未保存的输入。

分类与标签整合在“网站设置 → 导航与分类”，点击条目就地改名，网址与层级按需展开；首页分类目录与导航在同一分区调整，统一使用“保存设置”和“发布设置”。写作时选择或新建分类、标签直接在顶部弹层完成。新评论是否需要审核在“评论 → 评论设置”中调整。文章编辑页默认使用可视化编辑，收起管理导航，顶部保留返回、保存状态、预览和发布。格式工具栏上方常驻分类、标签、封面、发布选项和更多设置；公开/私密与评论使用开关。作者、网址、摘要、搜索分享和高级功能集中在“更多设置”中。检查、历史版本和本地草稿位于左下角“更多编辑操作”。

打开 `/admin/`，使用站主账户和密码登录，已有实例的默认账户名是 `owner`。开启两步验证后还需输入验证码或恢复码。后台“账户”可修改资料和密码、撤销其他登录、设置两步验证；恢复方法见[运行与恢复](operations.md)。内容列表可以按标题、状态、可见性和类型筛选，并按页加载。新建内容后填写标题、摘要和正文，右侧设置网址、作者、分类、标签、封面和自定义字段。分类标签可以从已有项目勾选或查找，也可以输入新名称添加；底层使用稳定编号，改名后关联保留。

新建内容默认使用可视化模式，提供标题、加粗、斜体、列表、引用、链接、代码、表格、媒体、撤销和重做。选中表格单元格后可以增删行列；插入媒体可从公用媒体库选择，插入后可以修改说明、图注或更换文件。链接可以从内容库选择，保存为稳定内容关联。Markdown 模式保留源码；不能无损转换的 HTML、指令或特殊语法继续使用源码模式。

内容及页面列表每行右侧的“⋯”菜单提供编辑、复制和删除。复制会打开一份正文及设置独立的新草稿，生成新网址，不自动发布。删除需要确认，会从内容库移除并撤下公开页面；内容库没有恢复入口，既有历史快照和共享媒体保留。待执行的发布任务、定时发布或仍引用该内容的发布计划需要先处理。列表状态由顶部分类切换表达，不重复显示状态标签。

输入停止约一秒后自动保存草稿，也可以按 Ctrl+S。浏览器会保留尚未保存的内容，重新打开时提供恢复入口。另一窗口已经保存时，后台暂停自动保存并打开对比：不同位置的改动可以合并，同一位置的改动需要选择本地或服务器内容。正文作为完整单元选择，避免把两种编辑格式混在一起。对比后服务器再次变化会要求重新比较。

浏览器按文章异步保存，每篇只保留一份最新的未保存草稿，持续覆盖更新；网站保存成功后清除对应草稿，不保留本地历史副本。最多保留四十篇、总量约 3 MiB。关闭或刷新网页前仍有未保存修改时，会触发浏览器的离开确认；确认框的文字由浏览器决定，网页不能自定义。存储失败会提示，网站保存仍可继续。上传媒体时按分块显示进度，中断后重新选择同一文件可继续已确认的部分。

“历史版本”可以选择两个修订，对照正文、字段和页面实际效果。恢复会创建新的工作稿，当前公开页面保持原版本。

草稿允许暂时缺少必填字段，已填写字段仍需符合其类型。发布会检查必填项和引用，未完成时给出具体错误。

“预览”先保存工作稿，再通过真实 Astro 渲染器打开指定修订，可切换桌面和窄屏宽度。预览不计入统计。只有点击发布后，新内容才进入前台；保存不会改变已经发布的页面。

点击“发布”先查看本次变更，再确认发布。查看后工作稿或公开版本变化会要求重新查看。网站设置中的“发布设置”只发布站点设置，不选择文章工作稿；“备份与维护 → 发布记录”中的全站发布会更新已有公开内容的改稿。

文章顶部“发布选项 → 定时发布”可安排发布时间，保存当时选定的修订；随后编辑的新工作稿仍然保留。计划在服务运行时到期执行，停机期间到期则在启动后补执行。待执行计划可以取消；失败会显示原因，可以重试同一修订或取消后重新安排。

“更多设置 → 搜索与分享”可覆盖搜索标题、摘要和分享图片；规范地址、页面语义和作者身份位于其中的“高级搜索设置”，空值沿用页面与网站默认信息。新建公开内容默认允许搜索引擎抓取，不需要逐篇勾选，实际收录由搜索引擎决定；编辑界面不再提供收录勾选项，也不会自动覆盖既有文章的收录设置。内容类型可选择默认语义，文章使用 Article，软件可选择 SoftwareApplication，普通页面使用 WebPage。发布者身份在“网站设置”中明确设置，不会把网站名称自动声明为一个人。

“来源与核验”记录说法、来源网址、核验日期和有效期。修改说法、来源名称或网址会退回待核验，保存后再确认核验状态；已核验记录需要完整信息和有效日期。来源随内容修订与发布，正文展示当前状态，只有未过期的已核验来源进入引用结构化数据。“已核验”是编辑者的确认，不代表框架自动验证了外部事实。

“网站检查”可以读取实际公开 HTTP 页面，或检查待发布内容的生成结果。报告列出覆盖、发现、证据与处理方法，支持筛选和分页；未能读取的页面保留未知。内容、设置、扩展或日期变化后，旧报告提示重新检查。“搜索数据”分区可导入标准搜索数据和 AI 回答记录，尚未接入、空数据和计划中未取得的样本分别显示。数据格式及 CLI 入口见[搜索与内容改进](seo-improvements.md)。

内容设置中的“可见性”支持公开和私密，与草稿、发布、归档状态独立。私密文章或页面发布后，只有登录后台的站主可以打开其网址，未登录访问返回 404；访客内容列表、搜索、RSS、站点地图和导航不包含它。修改可见性后点击发布才改变当前访客版本。私密页面和预览禁止缓存与索引，也不计入访问统计。

私密内容专用的本地媒体及响应式图片同样需要登录；如果同一张图片也被当前公开内容或公开设置引用，该图片属于共用的公开资源。历史私密修订引用的图片继续受到保护，撤下文章不会使这些图片公开。已有旧数据未设置可见性时按公开处理。

“网站设置 → 友情链接”直接填写网站名称、完整网址和简介，可以添加、移除或停用展示。“关于本站”填写普通介绍文字。保存设置保留工作稿，发布设置后才更新固定的前台界面，并自动在页脚显示入口。已有友情链接和关于页面沿用原网址；打开设置时只读取旧内容，只有修改了相应表单才采用新的固定界面，其它旧站内容保留。

文档模板根据正文二至四级标题生成目录和稳定锚点，桌面放在正文旁，窄屏放到正文前。正文目录也可放进自定义模板；搜索同时包含正文、页面区块及其引用的共享区域。

内容类型可以添加字段和字段组。数字、日期、选项、媒体地址、内容引用及重复字段均由字段定义校验。移除字段后旧值保留；重新加入同名字段可以继续读取。

字段勾选“可用于列表筛选”后，后台选择对应内容类型即可筛选，内容列表区块可选择显示访客筛选表单，也可以设置固定条件。分页保留当前条件。分类与标签在网站设置中编辑名称、网址标识和上级；同名子分类通过完整层级区分，内容选择保存稳定编号。发布设置会同时更新已保存的分类、标签和首页分类目录，不发布文章或布局工作稿。

网站设置中的网站、颜色、版心、间距、页脚和导航先保存为设置工作稿，再发布设置。迁移站额外显示平台与邀请设置。新增主题代码或扩展代码仍需要程序构建。

“网站设置 → 广告”提供网页顶部、网页底部、文章内顶部、文章内底部四个位置，可分别启用并填写 HTML。网页顶部广告位于页头导航下方，网页底部广告位于页脚上方。文章广告位于文章内容区域前后、评论之前，仅在内容详情页显示。默认主题和 Newsletter 均支持，搜索页、列表页和普通页面不会出现文章广告。可填写图片链接、内联样式、`<style>` 或广告平台的 `<script>`、`<iframe>` 代码，按原样输出。保存设置保留工作稿，发布设置后才更新访客页面；停用或代码为空时不占位，停用会保留原代码。文章预览使用设置工作稿，可在发布前查看效果；广告 HTML 与样式不会进入正文目录。

Newsletter 主题的文章页提供点赞、评论、分享和侧边目录。目录从正文二至四级标题生成，默认收起，点击侧边按钮展开；在“网站设置 → 文章目录”勾选“默认展开侧边目录”并发布设置，可改为进入文章时展开。文章封面用于列表和分享预览，不额外插入正文；摘要也不重复显示在文章开头。

Newsletter 首页的 RSS 订阅按钮下方可放置自定义 HTML。在“网站设置 → 首页侧栏”编辑并发布设置后生效，留空则隐藏。支持链接、图片、内联 SVG、CSS 和脚本，设置保存在 `extensions.newsletter.sidebarHtml`，随网站设置保存与发布。

默认主题和 Newsletter 均提供评论。访客无需注册即可填写称呼和评论，或选择已有评论回复；Newsletter 还提供点赞和取消点赞。评论必须通过图片验证码，验证码五分钟有效、单次使用，填写错误后需要换一张；同时限制验证码请求和评论提交频率。后台“评论”按状态筛选、分页浏览，可以审核、隐藏、恢复或以站主身份回复。独立站主标识只由服务端授予，访客使用同名不会获得该标识。隐藏评论不进入前台列表和计数，回复不显示隐藏父评论的称呼。互动数据保存在站点 SQLite 数据库中，随目录备份保留；私密文章和编辑预览不开放访客互动。

媒体库支持搜索、按类型筛选、改名、图片说明和图注、查看内容与布局引用，以及批量归档和恢复。裁切通过拖动选区或填写百分比生成副本，保留原文件和来源关系；私密原图的裁切副本继续受保护，明确发布为公开资源后才公开。归档不移除文件，也不影响已发布页面。

“备份与维护”提供 JSON 交换和 WordPress 标准 WXR 导入。选择文件和选项后先预检，再导入；预检后来源、选项或站点内容变化需要重新预检。转换报告列出页面、类型、分类、附件、评论和未转换的来源功能。未知插件区块、动态区块和短代码会要求在编辑页检查后才能发布。详细范围见迁移文档。
