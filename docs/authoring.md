# 使用与编辑

打开 `/admin/`，使用站主密码登录。内容列表可以按标题和状态筛选。新建内容后填写标题、摘要和正文，右侧设置网址、作者、分类、标签、封面和自定义字段。

编辑器默认使用可视化模式，提供标题、加粗、斜体、列表、引用、链接、代码、表格、图片、撤销和重做。Markdown 模式保留原始源码。含有不能无损转换的 HTML、指令或特殊语法时，会保持源码模式。来源资料迁移为可编辑 HTML 时也保持源码，不强行改写。

输入停止约一秒后自动保存草稿，也可以按 Ctrl+S。浏览器会保留尚未保存的内容，重新打开时提供恢复入口。遇到版本冲突后重新载入，避免覆盖另一窗口的修改。

草稿允许暂时缺少必填字段，已填写字段仍需符合其类型。发布会检查必填项和引用，未完成时给出具体错误。

“预览”先保存工作稿，再通过真实 Astro 渲染器打开指定修订，可切换桌面和窄屏宽度。预览不计入统计。只有点击发布后，新内容才进入前台；保存不会改变已经发布的页面。

页面编辑使用区块。可以添加、上下移动、复制和移除区块；分组和多列内部可继续添加区块。删除一个布局区块只改变工作稿，新版本发布前原页面仍然有效。历史修订中保留旧布局。

内容类型可以添加字段和字段组。数字、日期、选项、媒体地址、内容引用及重复字段均由字段定义校验。移除字段后旧值保留；重新加入同名字段可以继续读取。

外观与导航中的网站、颜色、版心、间距、页脚和导航先保存为设置工作稿，再发布设置。迁移站额外显示平台与邀请设置。新增主题代码或扩展代码仍需要程序构建。

媒体上传保留原文件，图片生成派生版本。媒体列表可以复制地址。内容归档和撤下不删除文件，旧修订和备份也不会自动清理。
