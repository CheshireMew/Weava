# 使用与编辑

打开 `/admin/`，使用站主密码登录。内容列表可以按标题、状态、可见性和类型筛选，并按页加载。新建内容后填写标题、摘要和正文，右侧设置网址、作者、分类、标签、封面和自定义字段。分类标签可以从已有项目勾选或查找，也可以输入新名称添加；底层使用稳定编号，改名后关联保留。

新建内容默认使用可视化模式，提供标题、加粗、斜体、列表、引用、链接、代码、表格、媒体、撤销和重做。选中表格单元格后可以增删行列；插入媒体可从公用媒体库选择，插入后可以修改说明、图注或更换文件。链接可以从内容库选择，保存为稳定内容关联。Markdown 模式保留源码；不能无损转换的 HTML、指令或特殊语法继续使用源码模式。

输入停止约一秒后自动保存草稿，也可以按 Ctrl+S。浏览器会保留尚未保存的内容，重新打开时提供恢复入口。另一窗口已经保存时，后台暂停自动保存并打开对比：不同位置的改动可以合并，同一位置的改动需要选择本地或服务器内容。正文作为完整单元选择，避免把两种编辑格式混在一起。对比后服务器再次变化会要求重新比较。

“历史版本”可以选择两个修订，对照正文、字段和页面实际效果。恢复会创建新的工作稿，当前公开页面保持原版本。

草稿允许暂时缺少必填字段，已填写字段仍需符合其类型。发布会检查必填项和引用，未完成时给出具体错误。

“预览”先保存工作稿，再通过真实 Astro 渲染器打开指定修订，可切换桌面和窄屏宽度。预览不计入统计。只有点击发布后，新内容才进入前台；保存不会改变已经发布的页面。

点击“发布”先查看本次变更，再确认发布。查看后工作稿或公开版本变化会要求重新查看。外观中的“发布设置”只发布站点设置，不选择文章工作稿；“运行与备份”中的全站发布会更新已有公开内容的改稿。

右侧可安排定时发布，保存当时选定的修订；随后编辑的新工作稿仍然保留。计划在服务运行时到期执行，停机期间到期则在启动后补执行。待执行计划可以取消；失败会显示原因，可以重试同一修订或取消后重新安排。

右侧“搜索与分享”可覆盖搜索标题、摘要、规范地址、分享图片、页面语义和作者身份；空值沿用页面与网站默认信息。内容类型也可选择默认语义，文章使用 Article，软件可选择 SoftwareApplication，普通页面使用 WebPage。发布者身份在“外观与导航”中明确设置，不会把网站名称自动声明为一个人。

“来源与核验”记录说法、来源网址、核验日期和有效期。修改说法、来源名称或网址会退回待核验，保存后再确认核验状态；已核验记录需要完整信息和有效日期。来源随内容修订与发布，正文展示当前状态，只有未过期的已核验来源进入引用结构化数据。“已核验”是编辑者的确认，不代表框架自动验证了外部事实。

“搜索与检查”可以读取实际公开 HTTP 页面，或检查待发布内容的生成结果。报告列出覆盖、发现、证据与处理方法，支持筛选和分页；未能读取的页面保留未知。内容、设置、扩展或日期变化后，旧报告提示重新检查。下方可导入标准搜索数据和 AI 观测，尚未接入、空数据和计划中未取得的样本分别显示。数据格式及 CLI 入口见[搜索与内容改进](seo-improvements.md)。

发布设置中的“可见性”支持公开和私密，与草稿、发布、归档状态独立。私密文章或页面发布后，只有登录后台的站主可以打开其网址，未登录访问返回 404；访客内容列表、搜索、RSS、站点地图和导航不包含它。修改可见性后点击发布才改变当前访客版本。私密页面和预览禁止缓存与索引，也不计入访问统计。

私密内容专用的本地媒体及响应式图片同样需要登录；如果同一张图片也被当前公开内容或公开设置引用，该图片属于共用的公开资源。历史私密修订引用的图片继续受到保护，撤下文章不会使这些图片公开。已有旧数据未设置可见性时按公开处理。

页面和包含区块的导入内容使用真实页面画布。点击区块选择设置，主视觉标题和说明可在画布中双击编辑。可以添加、上下移动、复制和移除区块；分组和多列内部可继续添加区块。桌面、平板、手机分别预览实际宽度，可设置列数、间距、背景和版心。移除布局区块只改变工作稿，发布前原页面仍然有效，历史修订保留旧布局。

“布局”管理模板、共享区域和区块组合。模板决定标题、正文和字段的位置；每个模板保留一个正文占位。共享区域在引用位置统一更新，区块组合插入后成为独立区块。内容类型可设置默认模板，单篇内容也可以覆盖。外观设置可指定页头、正文前后和页脚区域。“发布布局”独立发布布局工作稿；换主题会保留页面内容与模板选择。

文档模板根据正文二至四级标题生成目录和稳定锚点，桌面放在正文旁，窄屏放到正文前。正文目录也可放进自定义模板；搜索同时包含正文、页面区块及其引用的共享区域。

内容类型可以添加字段和字段组。数字、日期、选项、媒体地址、内容引用及重复字段均由字段定义校验。移除字段后旧值保留；重新加入同名字段可以继续读取。

字段勾选“可用于列表筛选”后，后台选择对应内容类型即可筛选，内容列表区块可选择显示访客筛选表单，也可以设置固定条件。分页保留当前条件。分类与标签在独立管理页编辑名称、网址标识和上级；同名子分类通过完整层级区分，内容选择保存稳定编号。“发布分类和标签”不会顺带发布内容、布局或网站设置工作稿。

外观与导航中的网站、颜色、版心、间距、页脚和导航先保存为设置工作稿，再发布设置。迁移站额外显示平台与邀请设置。新增主题代码或扩展代码仍需要程序构建。

Newsletter 主题的文章页提供点赞、评论、分享和侧边目录。目录从正文二至四级标题生成，默认收起，点击侧边按钮展开；在“外观与导航 → 文章目录”勾选“默认展开侧边目录”并发布设置，可改为进入文章时展开。文章封面用于列表和分享预览，不额外插入正文；摘要也不重复显示在文章开头。

访客无需注册即可点赞、取消点赞，以及填写称呼和评论。评论必须通过图片验证码，验证码五分钟有效、单次使用，填写错误后需要换一张；同时限制验证码请求和评论提交频率。后台“评论”按状态筛选、分页浏览，可以隐藏或恢复评论。隐藏评论不进入前台列表和计数。互动数据保存在站点 SQLite 数据库中，随目录备份保留；私密文章和编辑预览不开放访客互动。

媒体库支持搜索、按类型筛选、改名、图片说明和图注、查看内容与布局引用，以及批量归档和恢复。裁切通过拖动选区或填写百分比生成副本，保留原文件和来源关系；私密原图的裁切副本继续受保护，明确发布为公开资源后才公开。归档不移除文件，也不影响已发布页面。

“运行与备份”提供 JSON 交换和 WordPress 标准 WXR 导入。选择文件和选项后先预检，再导入；预检后来源、选项或站点内容变化需要重新预检。转换报告列出页面、类型、分类、附件、评论和未转换的来源功能。未知插件区块、动态区块和短代码会要求在编辑页检查后才能发布。详细范围见迁移文档。
